# Como contribuir

1. Consulte `README.md`, `.ai/CONTEXT.md`, `.ai/DECISIONS.md`, `.ai/STATUS.md` e os documentos relacionados antes de alterar o projeto.
2. Vincule cada alteração ou tarefa a um cartão do [Trello](https://trello.com/b/RkWOzDcu/desenvolvimento-de-projetos-mix7). Crie um cartão se não houver um correspondente.
3. Faça mudanças pequenas e completas em uma branch própria. Abra pull request com o problema, comportamento resultante, validação executada e riscos relevantes.
4. Depois de cada alteração e tarefa concluída, crie commit, faça push, confirme o commit remoto e atualize o cartão do Trello com resultado, estado e link para commit ou pull request **antes de declarar a entrega concluída**.
5. Integre mudanças na `main` por pull request. Não faça `force push`, não reescreva commits publicados nem exclua branches ou tags sem autorização explícita. Use tags anotadas e publicadas para marcos importantes.
6. Preserve alterações existentes e atualize documentação e `.ai/STATUS.md` quando a mudança material estiver concluída. Registre decisões novas em `.ai/DECISIONS.md`. Se uma das sincronizações falhar, registre a pendência e não informe que as fontes estão atualizadas.
7. Não inclua senhas, tokens, dados de clientes, áudios originais ou arquivos de produção sem necessidade e autorização. Use exemplos fictícios para testes e documentação.

Não há comandos de instalação ou testes de aplicação neste momento; a stack ainda será decidida.
