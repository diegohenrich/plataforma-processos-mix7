# Como contribuir

1. Consulte `README.md`, `.ai/CONTEXT.md`, `.ai/DECISIONS.md`, `.ai/STATUS.md` e os documentos relacionados antes de alterar o projeto.
2. Use o [Trello](https://trello.com/b/RkWOzDcu/desenvolvimento-de-projetos-mix7) para acompanhar entregas e perguntas. Relacione o cartão no pull request quando houver implementação.
3. Faça mudanças pequenas e completas em uma branch própria. Abra pull request com o problema, comportamento resultante, validação executada e riscos relevantes.
4. Preserve alterações existentes e atualize documentação e `.ai/STATUS.md` quando a mudança material estiver concluída. Registre decisões novas em `.ai/DECISIONS.md`.
5. Não inclua senhas, tokens, dados de clientes, áudios originais ou arquivos de produção sem necessidade e autorização. Use exemplos fictícios para testes e documentação.

Não há comandos de instalação ou testes de aplicação neste momento; a stack ainda será decidida.
